Security

Powerful, with brakes.

Every tool declares its risk level. Sensitive actions get confirmed, irreversible ones never happen silently, and an emergency stop is always one click away.

  • Credentials encrypted in Windows Credential Manager, never in the code.
  • Web pages, documents and external messages are treated as untrusted.
  • The interface only listens on 127.0.0.1 and Telegram requires pairing and a PIN.
  • Never disables the antivirus or firewall, never keeps admin rights.
safe

Read only. Runs without asking.

moderate

Reversible changes. Logged.

sensitive

Privacy or relevant changes. Asks first.

dangerous

Always needs explicit approval, with a PIN from Telegram.

One command and you're running.

The installer sets up Python, Ollama and the right models for your hardware. No administrator rights needed.

PowerShell
# 1. Get the project
git clone https://github.com/ItsTrako/jarvis.git C:\JARVIS
cd C:\JARVIS

# 2. Install everything (or double-click INSTALAR.cmd)
.\INSTALAR.cmd

# 3. Start it
.\Jarvis.cmd
  1. RequirementsWindows 10 or 11. Recommended: 16 GB of RAM and an NVIDIA GPU for voice and local AI.
  2. No Git?Download the ZIP from GitHub, extract it to C:\JARVIS and open INSTALAR.cmd.
  3. Claude, optionalIt works for free from the start. Add your Anthropic key in the settings whenever you like.
